# RSNA Knee V52 RadImageNet heads

This release contains the five frozen prediction heads produced by version 52 of
`prvsiyan/rsna-knee-read-the-report-then-the-knee`.  The heads were trained only
from the RSNA Knee competition training split.  They consume the 24 RadImageNet
ResNet-50 slice descriptors generated by that notebook's exact three-plane,
eight-slice preprocessing contract.

The bundle is published so code-competition inference can reproduce the trained
V52 model without rebuilding all 4,407 training-study features during each
scoring run.  It does not contain test images, test identifiers, test features,
or test predictions.

## Provenance and terms

The prediction heads are a competition-training-derived artifact.  Their frozen
feature contract depends on the official RadImageNet ResNet-50 checkpoint used
by the source notebook.  RadImageNet's released checkpoint and the Kaggle-hosted
copy used by V52 are attributed in the notebook; downstream users remain
responsible for complying with the competition rules and upstream license,
including its non-commercial/share-alike restrictions where applicable.
